# Contributing

By contributing you agree that your work is licensed under the GNU Affero General Public License v3.0 (see [LICENSE](LICENSE)).

- Keep Ektie credentials, env files, and customer media out of this repository.
- Editor behavior lives in `packages/editor`. The Next.js app in `demo/nextjs` should only consume the public API.
- Run `npm test` before opening a PR.
- Run `npm run security-scan` if you touch copy/paste from another codebase.
