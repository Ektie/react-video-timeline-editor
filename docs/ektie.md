# Ektie Creative

This open-source repository does **not** include or modify Ektie CRM.

[Ektie Creative](https://ektie.com/creative) is a separate commercial product that can consume `@ektie/react-video-timeline-editor` the same way the Next.js demo does: import the package, pass a project document, and supply host adapters for assets, persistence, and export.

Those adapters belong in the Ektie application, not here.
